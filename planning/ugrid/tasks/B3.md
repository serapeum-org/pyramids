## Objective

Area/overlap-weighted, first-order-conservative, barycentric, and centroid-locator regridding between
meshes (and structured↔unstructured). This is the single biggest capability gap versus xugrid and the
largest task. Requires a new ADR (see §S.8 — B3 is explicitly called out) before coding.

## ⚠️ Dependency decision (record BEFORE coding — §S.7)

The overlap-area computation requires **exact polygon–polygon intersection area**. Two routes; pick and
record the choice in the ADR:

- **Route 1 (RECOMMENDED): add `numba_celltree` behind a new `[mesh]` optional extra** and call
  `celltree.intersect_faces(vertices, faces, fill_value)` → `(target_index, source_index, weights)`, where
  `weights` is the clipped-intersection area (verified: xugrid `regrid/unstructured.py:109`). This is what
  xugrid uses: correct, fast, battle-tested (`intersect_faces` / `locate_points` / `intersect_edges`). Con:
  a new heavy dep (numba).
- **Route 2 (numpy-only)** is acceptable **only** for **CentroidLocator** (point-in-face) and
  **Barycentric-via-gridded-alphas**. **True conservative regridding needs Route 1.**

**NEVER** hand-roll polygon clipping / vendor a partial polygon-intersection area — an approximate overlap
area silently corrupts conservative regridding (§S.7). Use Route 1 for true area-overlap.

When Route 1 is chosen: gate `numba_celltree` behind the `[mesh]` extra with a clean
`OptionalPackageDoesNotExist` when absent, and follow the §S.8 new-extra checklist (add to
`[project.optional-dependencies]`; register a `mesh:` marker line; add a `_has("numba_celltree")` probe +
mapping in `tests/_marks.py`; mark tests `@pytest.mark.mesh`).

## Public API

A new `ugrid/regrid/` subpackage exposing:
- `OverlapRegridder`, `RelativeOverlapRegridder`, `CentroidLocatorRegridder`, `BarycentricInterpolator`.
- Each: `__init__(source, target, ...)`, `.regrid(data_or_dataset)`, `.weights`, classmethod
  `.from_weights(weights, target)`.
- Facade: `UgridDataset.regrid(self, target, method=..., ) -> UgridDataset`.

## Where it exists / reference design (xugrid, verified)

- **Weight storage:** build COO triplets `(target_index, source_index, weight)`; convert to CSR
  (`core/sparse.py`, rows sorted by target). Row *t* = `indices[indptr[t]:indptr[t+1]]`. Persist/reuse
  weights (`from_weights`) — first-class feature: weights computed **once**, applied to many time/layer
  slabs.
- **Absolute vs relative:** `RelativeOverlapRegridder` divides each weight by the **source** face area
  (`weights /= source_area[source_index]`) → enables `first_order_conservative` (`Σ v·w`). Face area =
  shoelace (already in `mesh.face_areas`).
- **Aggregation methods** (all NaN-aware; return NaN when `Σw == 0`), from `regrid/reduce.py`:
  `mean = Σwv/Σw`, `sum`, `minimum`, `maximum`, `mode` (area-weighted, tie → largest value),
  `harmonic_mean`, `geometric_mean`, `max_overlap`, `first_order_conservative`, and percentiles/median
  (quickselect, ranks `1 + (n-1)·p/100`).
- **CentroidLocator:** `source_index = tree.locate_points(target_centroids)`; weight 1.0; pure copy
  (COO 1:1). Points outside → dropped.
- **Barycentric:** build the centroidal-Voronoi tesselation of the source (see E4), then celltree
  barycentric weights of target centroids in the voronoi mesh, remapping voronoi vertices → source faces;
  exterior interpolated vertices redistributed to the two surrounding real nodes by inverse-distance
  (xugrid `regrid/unstructured.py:17` `replace_interpolated_weights`).

## pyramids internals you must know

- `mesh.face_areas` — shoelace face areas (source areas for the relative/conservative divide).
- `mesh.face_centroids` — target centroids for CentroidLocator / Barycentric.
- B2's point-sampling + `MeshSpatialIndex` are your building blocks (dependency B2).
- Follow §S.4 for returning results (keep-same-mesh vs rebuild-mesh); the regridded result lives on the
  **target** mesh — construct the output `UgridDataset` on the target, carrying attributes.

## Implementation steps

1. Write the ADR (regridder subpackage + `numba_celltree`/`[mesh]` dep decision).
2. Build the weight-computation for each regridder → COO triplets → CSR (rows sorted by target).
3. Implement the NaN-aware aggregation kernels from `regrid/reduce.py`.
4. Implement `RelativeOverlapRegridder` (divide weights by source face area) and `first_order_conservative`.
5. Implement `CentroidLocatorRegridder` (locate_points, weight 1.0, drop outside).
6. Implement `BarycentricInterpolator` (needs Voronoi tesselation — coordinate with E4;
   `replace_interpolated_weights` for exterior vertices).

8. Broadcast over leading time/layer axes: **loop the "extra" dims, apply the sparse matmul per slab**.
9. Facade `UgridDataset.regrid(target, method=...)`.

## Correctness / regression traps

- Overlap weights must be **true intersection areas** (Route 1) — never an approximation.
- Output **pre-filled NaN**; empty target rows stay NaN.
- Conservative method must divide by **source** area (not target).
- Broadcast over leading time/layer axes (loop the extra dims, apply the sparse matmul per slab).
- `mode` tie-break must be **order-independent** (largest value).
- Overlap-mean of a constant field = that constant.

### S.1 — The mesh-dimension model (get this right or you introduce bugs)

A `UgridDataset` has **no (row, col) grid**. Each field is a `MeshVariable` on exactly one location —
`node` / `face` / `edge` (`MeshVariable.location`). Counts: `n_node = len(node_x)`,
`n_face = face_node_connectivity.n_elements`, `n_edge = edge_node_connectivity.n_elements` (0 if no edge
connectivity).

`MeshVariable.data` shape invariants (verified in `models.py`):

| kind | `data.shape` | element axis | time axis |
|------|--------------|--------------|-----------|
| static face var | `(n_face,)` | `-1` | — (`has_time=False`) |
| temporal face var | `(n_time, n_face)` | `-1` | `0` (`time_index=0`) |
| layered, non-temporal | `(n_layers, n_face)` | `-1` | none (`time_index is None`, ARC-19) |
| temporal + layered | `(n_time, n_layers, n_face)` | `-1` | `time_index` |

**Rules:**
1. **Element axis is always last (`-1`).** Index/slice elements with `arr[..., idx]` so leading
   time/layer axes are preserved (this is how `spatial.py:_subset_mesh_by_face_indices` slices).
2. **Time axis is `MeshVariable.time_index`** (0 for temporal, else `None`). Never assume "extra axis ==
   time" — a `(n_layers, n_face)` var is NOT temporal. `time_index` (`models.py:166`) matches CF dim
   names (`time`/`t`/`time…`/`…_time`/`…_time_…`) with word-boundary logic (avoids `runtime`/`lifetime`).
3. **Reduce/select over `"time"`** → result is still on the mesh → return a new `UgridDataset`.
4. **Reduce over the element axis** (`"face"`/`"node"`/`"edge"`/`"space"`) collapses the mesh → return a
   **tabular** result (`pandas.DataFrame` indexed by time, or `dict[str, np.ndarray]`), NOT a
   `UgridDataset`.
5. **Only touch variables the dim exists on.** A dataset-wide `dim="time"` op processes temporal vars and
   **carries static/layered vars through unchanged** (don't error).

### S.2 — Facade/engine house pattern (mirror it)

pyramids implements its whole xarray-parity surface **in pyramids** (numpy, no xarray at runtime) with:
thin **facade** methods on the container + **engine** bodies under `src/pyramids/netcdf/engines/` + grouped
**`@dataclass(frozen=True)`** option objects (see `netcdf/plot_options.py`, `netcdf/array_options.py`;
all fields defaulted, validation in `__post_init__`, `as_dict()` where useful).

For the mesh: put engine bodies in a **new** `src/pyramids/netcdf/ugrid/engines/` package (mirror
`netcdf/engines/`); keep `UgridDataset` methods as thin facades. **Reuse existing numpy op bodies** —
they are per-axis kernels, not xarray:
- `src/pyramids/netcdf/engines/_along_dim.py` — `_Reduction`, `_Rolling`, `_Diff`, `_CumSum`, `_Shift`,
  `_Extremum`, `_DropNa`, ffill/bfill/interp ops + the `_apply_to_variable` loop. If a helper is too
  `NetCDF`-coupled, lift its pure-numpy core into a shared helper rather than copy-pasting.
- `src/pyramids/dataset/_reduce_ops.py:20` — `resolve_dask_op(op_name, *, skipna)` → `dask.array.nan*`
  (lazy path).
- `src/pyramids/netcdf/engines/_weighted.py` — weighted-mean math.
- `src/pyramids/netcdf/engines/combine.py` — `concat`/`merge` structure; the `@_joins_cubes` decorator
  (`netcdf.py:2111`) makes them callable both as `Cls.concat([a,b], dim)` and `a.concat([b], dim)`.

### S.3 — `MeshVariable` contract (how to return derived data)

To produce a derived variable, **always** use `MeshVariable.with_data(new_array)` (`models.py:322`): an
eager copy preserving `name`, `location`, `mesh_name`, `attributes`, `nodata`, `units`, `standard_name`,
`dimensions`, with `shape` from `new_array.shape`. Never hand-build `MeshVariable(...)` in derived ops.

⚠️ **`dimensions` bookkeeping:** `with_data` copies `dimensions` verbatim. If your op **removes** an axis
(e.g. `reduce(dim="time")`), the returned `dimensions` is stale. Add an optional `dimensions=` override to
`with_data` (or set `_data`+`shape`+`dimensions` consistently) and assert `dimensions` length == `data.ndim`.

⚠️ **`from_arrays` does not set `dimensions`** (`dataset.py:800`;
`from_arrays(node_x, node_y, face_node_connectivity, data=None, data_locations=None, epsg=4326, mesh_name=...)`).
So an array-built `(n_layers, n_face)` var has `dimensions=()` and is **mis-detected as temporal** by the
leading-axis fallback (`models.py:191`). Fixes: (a) **recommended** — add an optional
`dimensions: dict[str, tuple[str,...]] | None` to `from_arrays`, threaded into each
`MeshVariable(dimensions=...)`; or (b) for one-off tests, construct `MeshVariable(..., dimensions=(...))`
directly and assemble `UgridDataset(mesh=..., data_variables={...}, global_attributes={...})` by hand.
File-read datasets are unaffected (`_read_data_variables` fills `dimensions` from GDAL dims).

### S.4 — Rewrapping into a `UgridDataset` (avoid the import cycle)

- Ops that **rebuild the mesh** (topology subset) live as standalone functions in `spatial.py` (or a new
  sibling) and return a **`(Mesh2d, dict[str, MeshVariable])` tuple**, never a `UgridDataset` —
  `TestNoImportCycle` asserts `spatial.py` has no module-scope import of `ugrid.dataset`. The facade then
  calls `self._wrap_subset(mesh, data_vars)` (`dataset.py:434`), which carries
  `global_attributes`/`topology_info`/`crs_wkt` and sets `file_name=None`.
- Ops that **keep the same mesh** (all time-axis ops) build `new_data_vars: dict[str, MeshVariable]` and
  construct `UgridDataset(mesh=self._mesh, data_variables=new_data_vars, global_attributes=self._global_attributes, topology_info=self._topology_info, crs_wkt=self._crs_wkt)` directly (as `sel_time` does ~`dataset.py:599`).

### S.7 — Geometry-dep policy (only relevant to overlap-regridding / polygon-burning)

Overlap/conservative/barycentric regridding and polygon-burning need a **cell-tree + polygon-clipping
engine**. Two routes — **record the choice before coding**: (1) **wrap `numba_celltree`** behind a new
`[mesh]` optional extra (what xugrid uses; correct area-overlap via `celltree.intersect_faces`); (2)
**pure numpy/scipy** for the subset that needs no polygon clipping — nearest/barycentric **point** sampling
(gridded's closed-form triangle alphas), nearest-fill, Laplace, connectivity/graph ops, `from_structured`,
`polygonize` (shapely only). **Never** hand-roll polygon-intersection area for conservative regridding —
an approximate area silently corrupts it; use route 1.
