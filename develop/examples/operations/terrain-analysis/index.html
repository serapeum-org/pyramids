    Terrain analysis from a DEM¶

    Derive terrain products from an elevation raster:

    • slope — steepness (degrees or percent).
    • aspect — the compass direction a slope faces.
    • hillshade — shaded relief for a given sun position.
    • proximity — distance from each cell to the nearest target cell.

    slope / aspect / hillshade return NumPy arrays; proximity returns a Dataset.

    Slope and aspect¶

    units='degrees' (default) or 'percent' for slope; aspect is in degrees.

    In [4]:
    Copied! 
    slope = dem.slope(units='degrees')
aspect = dem.aspect()
slope.shape, float(np.nanmin(slope)), float(np.nanmax(slope)), aspect.shape
    slope = dem.slope(units='degrees') aspect = dem.aspect() slope.shape, float(np.nanmin(slope)), float(np.nanmax(slope)), aspect.shape
    Out[4]:
    ((125, 93), 0.0, 2147483647.0, (125, 93))

    Slope returns a NumPy array — wrap it back into a Dataset matching the DEM's grid to plot it. Steeper cells show up brighter.

    Hillshade¶

    Shaded relief for a sun at azimuth (compass °) and altitude (° above horizon).

    In [6]:
    Copied! 
    shade = dem.hillshade(azimuth=315.0, altitude=45.0)
shade.shape, float(np.nanmin(shade)), float(np.nanmax(shade))
    shade = dem.hillshade(azimuth=315.0, altitude=45.0) shade.shape, float(np.nanmin(shade)), float(np.nanmax(shade))
    Out[6]:
    ((125, 93), 68.68723032180287, 2147483647.0)

    Hillshade is a NumPy array too — wrapped into a Dataset and drawn in grayscale for classic shaded relief (sun at NW, 45° above the horizon).

    Proximity¶

    Euclidean distance from every cell to the nearest cell holding a target value (here, cells equal to 1). Returns a Dataset whose values are distances in the raster's units (GEO).

    In [8]:
    Copied! 
    dist = dem.proximity(target_values=[1], distance_units='GEO')
type(dist).__name__, dist.shape
    dist = dem.proximity(target_values=[1], distance_units='GEO') type(dist).__name__, dist.shape
    Out[8]:
    ('Dataset', (1, 125, 93))

    Proximity returns a Dataset directly — each cell's value is its distance to the nearest target cell, so values grow with distance from the targets.

    In [9]:
    Copied! 
    dist.plot(band=0, title="Proximity (distance to target)", cmap="cividis")
    dist.plot(band=0, title="Proximity (distance to target)", cmap="cividis")
    Out[9]:
    <cleopatra.glyphs.gridded.array_glyph.ArrayGlyph at 0x7fccfbdf0d60>

    Notes¶

    • All of these also accept chunks= to run lazily on a Dask array — see the Dask quickstart — Dataset.
    • To render a hillshade or slope, wrap the array back into a Dataset and use Visualization.
