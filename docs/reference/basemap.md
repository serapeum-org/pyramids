# Basemap

Add web-tile basemaps (OpenStreetMap and other XYZ providers) under a plotted raster or vector.

- `get_provider` — resolve a tile provider by name.
- `add_basemap` — draw a basemap onto a matplotlib axes.

See the [Basemap example](../examples/basemap/basemap-example.ipynb) for a runnable walkthrough.
Requires the `[viz]` extra.

::: pyramids.basemap.get_provider
    options:
        show_root_heading: true
        show_source: true
        heading_level: 3

::: pyramids.basemap.add_basemap
    options:
        show_root_heading: true
        show_source: true
        heading_level: 3
